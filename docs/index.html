What is LingAI?

An end-to-end spoken language identification system built with deep learning

🎯

14-Language Classification

Identifies spoken language from audio across Dravidian, Indo-Aryan, Germanic, Romance, and Sino-Tibetan language families.

🧠

Deep LSTM Model

Two-layer LSTM network trained on 64-dimensional MFCC sequences, capturing temporal phonetic and prosodic patterns.

🇮🇳

Indian Language Focus

9 of 14 languages are Indian regional languages — Hindi, Tamil, Telugu, Kannada, Malayalam, Bengali, Marathi, Gujarati, and Punjabi.

💻

CPU Deployable

Lightweight architecture runs entirely on standard hardware without requiring GPU infrastructure.

📊

Visual Explanations

Ranked confidence scores, MFCC spectrogram visualization, and linguistic family context for every prediction.

🔐

User Authentication

Secure login and registration with SHA-256 password hashing and session management.

Model Architecture

Deep LSTM network trained on 64-dimensional MFCC sequences

  Input Layer     →  (1000, 64)      — 1000 time steps × 64 MFCC features
       ↓
  LSTM Layer 1    →  64 units        — Sequence-to-sequence, captures phoneme transitions
       ↓
  LSTM Layer 2    →  32 units        — Sequence-to-sequence, captures prosodic patterns
       ↓
  Dropout         →  rate = 0.15     — Regularization
       ↓
  Dense Layer     →  100 units, tanh — Non-linear feature compression
       ↓
  Output Layer    →  14 units        — Softmax → language probability distribution

📉

Loss Function

Categorical Cross-Entropy — measures divergence between predicted language probabilities and true one-hot labels.

⚡

Optimizer

Adam with initial LR 0.002 and ReduceLROnPlateau scheduler (factor=0.5, patience=3 epochs).

🔁

Training Config

28 epochs, batch size 16, 85/15 train-validation split. Saved as sld.keras and sld.weights.h5.

Processing Pipeline

From raw audio to language prediction in 6 stages

1 — Speech Synthesis

gTTS generates 5 utterances per language, resampled to 16kHz mono WAV

2 — Audio Augmentation

Pitch shift (±1, ±2), time stretch (0.9×, 1.1×), noise addition → 9× samples

3 — MFCC Extraction

64-dim MFCCs at 100fps → (1000, 64) matrix with CMVN normalization

4 — HDF5 Dataset

All features and one-hot labels compiled into mfcc_dataset.hdf5

5 — LSTM Training

Model trained for 28 epochs, saved as sld.keras

6 — Streamlit Deployment

Real-time inference via web app with confidence scores and MFCC visualization
