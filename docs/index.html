📈 MFCC Feature Extraction Pipeline
Raw Audio (WAV, 16kHz, mono) ↓ Pre-emphasis Filter → Removes low-freq noise ↓ Frame Splitting → 25ms frames, 10ms hop (100fps) ↓ Hamming Window → Reduces spectral leakage ↓ FFT → Frequency domain conversion ↓ Mel Filter Banks → 64 triangular filters ↓ Log Compression → Mimics human hearing ↓ DCT → Decorrelates features → 64-dim MFCC ↓ CMVN Normalization → Zero mean, unit variance per feature ↓ Output Shape → (1000, 64) — ready for LSTM input
